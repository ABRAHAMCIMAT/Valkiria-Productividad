# Dataset `formato` v1 (fixture de F0)

Cinco salidas ya generadas, sin datos personales ni reales de VALTRE. En F0 no hay modelos cargados:
el dataset sirve para probar la cadena de trazabilidad (run etiquetado → gate → exportación).
Su SHA-256 se usa como `model.sha256` del run de ejemplo (decisión D5 del plan de F0); en F1 se
sustituye por el SHA-256 del modelo GGUF evaluado.
